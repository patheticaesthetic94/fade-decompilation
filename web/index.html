    Fade

    The 2001 Pocket PC adventure by Fade Team, recompiled from the original game to run natively in your browser.

    Controls

    • Tap the screen to interact. Tap the lower-right arrow to continue text.
    • The direction pad or arrow keys navigate. Enter / Z, X and C are the hardware buttons.
    • The power button returns to the edition choice.
    • While this screen or the walkthrough is open, the direction pad scrolls it and the action button closes it.

    Editions

    Classic is the game as released. Remastered adds 4× artwork, outline text and enhanced sound, and is a larger download. Both are stored on this device after the first download.

    Screen filter

    Recreates a 2001 3.8″ transflective panel: the 240×320 pixel grid with RGB stripes, 65,536 colours, raised blacks and a narrow gamut, an uneven front light and slow pixel response. It can be switched on or off while playing.

    Saves

    Use the game’s Save command. Saves stay in this browser and are shared by both editions. Clearing site data removes them, and private browsing may not keep them, so download a backup now and then.
